# Requirements Document

## Introduction

회원이 마음에 드는 상품을 **찜 목록**에 담아 두고, 빼고, 모아 볼 수 있는 기능입니다.
찜은 주문 · 결제와 관계가 없고, 상품 정보는 주문과 같은 상품 카탈로그에서 확인합니다.

- 범위 밖: 찜한 상품의 가격 변동 알림, 찜 목록에서 바로 주문하기, 찜 목록 공유
- API 경로, 클래스, 테이블 등 구현 정보는 [design.md](design.md)에 있습니다.

## Glossary

- **회원 (Member)**: 찜 목록을 가진 사용자. 자신의 찜 목록만 보고 다룰 수 있다
- **상품 (Product)**: 판매 대상. 상품명, 판매가, 판매 여부를 가진다
- **상품 카탈로그 (Product Catalog)**: 상품 정보를 제공하는 외부 시스템. 찜 기능은 조회만 한다
- **찜 목록 (Wishlist)**: 회원이 나중에 다시 보려고 담아 둔 상품 목록. 회원마다 하나다
- **찜 (Wish)**: 찜 목록에 담긴 상품 하나와 담은 일시
- **판매 상태 (Sale Status)**
  - 판매 중 (`ON_SALE`): 상품 카탈로그에 있고 판매 중인 상품
  - 판매 중지 (`NOT_ON_SALE`): 상품 카탈로그에 있지만 지금은 판매하지 않는 상품
  - 판매 종료 (`DISCONTINUED`): 상품 카탈로그에 더는 없는 상품

## Requirements

### Requirement 1: 상품 찜하기

**User Story:** As a 회원, I want to 마음에 드는 상품을 찜 목록에 담을 수 있어야, so that 나중에 다시 찾아볼 수 있다

#### Acceptance Criteria

##### 처리 흐름

1. **회원은 상품을 찜 목록에 담을 수 있다.**
   - 요청 정보: 상품

2. **이미 찜한 상품을 다시 담아도 성공으로 본다.** 찜 목록을 바꾸지 않는다.
   - 응답: `200` — 기존 찜 (상품, 담은 일시)
   - 이유: 버튼을 여러 번 눌러도 회원이 오류를 보지 않게 한다

3. **찜 목록에는 상품을 100개까지 담을 수 있다.** 100개가 차 있으면 더 담을 수 없다.
   - 경계: 99개일 때 담기 가능, 100개일 때 불가
   - 에러: `409` `WISHLIST_FULL`
   - 메시지: "찜 목록은 100개까지 담을 수 있습니다."

4. **담으려는 상품이 있는지 상품 카탈로그에서 확인한다.**

5. **상품 정보를 확인할 수 없으면 담을 수 없다.** (상품 카탈로그 장애)
   - 에러: `503` `PRODUCT_CATALOG_UNAVAILABLE`
   - 메시지: "상품 정보를 확인할 수 없습니다. 잠시 후 다시 시도해주세요."

6. **존재하지 않는 상품은 담을 수 없다.**
   - 에러: `404` `PRODUCT_NOT_FOUND`
   - 메시지: "상품을 찾을 수 없습니다."
   - 판매 중이 아닌 상품은 담을 수 있다

7. **상품을 찜 목록에 담는다.**
   - 찜: 상품, 담은 일시

8. **담은 찜을 응답한다.**
   - 응답: `201` — 상품, 담은 일시

##### 항상 지켜야 할 규칙

9. **같은 상품은 찜 목록에 한 번만 담긴다.** 같은 상품을 동시에 여러 번 담아도 찜은 하나다.

### Requirement 2: 찜 해제

**User Story:** As a 회원, I want to 찜한 상품을 찜 목록에서 뺄 수 있어야, so that 관심 없어진 상품을 정리할 수 있다

#### Acceptance Criteria

##### 처리 흐름

1. **회원은 찜한 상품을 찜 목록에서 뺄 수 있다.**
   - 요청 정보: 상품

2. **찜 목록에 없는 상품을 빼도 성공으로 본다.** 아무것도 바꾸지 않는다.
   - 응답: `204`

3. **상품을 찜 목록에서 뺀다.**

4. **뺀 뒤에는 내용 없이 성공을 응답한다.**
   - 응답: `204`

##### 항상 지켜야 할 규칙

5. **찜을 빼는 동안 상품 카탈로그를 조회하지 않는다.**
   - 이유: 상품이 판매 종료되었거나 상품 카탈로그에 장애가 있어도 찜을 뺄 수 있어야 한다

### Requirement 3: 찜 목록 조회

**User Story:** As a 회원, I want to 내 찜 목록을 한눈에 볼 수 있어야, so that 담아 둔 상품의 지금 가격과 판매 여부를 확인할 수 있다

#### Acceptance Criteria

##### 처리 흐름

1. **회원은 자신의 찜 목록을 볼 수 있다.**

2. **찜한 상품의 지금 상품명, 판매가, 판매 여부를 상품 카탈로그에서 확인한다.**
   - 찜 목록이 비어 있으면 상품 카탈로그를 조회하지 않는다

3. **상품 정보를 확인할 수 없으면 찜 목록을 보여줄 수 없다.** (상품 카탈로그 장애)
   - 에러: `503` `PRODUCT_CATALOG_UNAVAILABLE`
   - 메시지: "상품 정보를 확인할 수 없습니다. 잠시 후 다시 시도해주세요."

4. **상품 카탈로그에 없는 상품은 판매 종료로 보여준다.** 찜 목록에서 빼지 않는다.
   - 이유: 회원이 직접 정리하게 한다

5. **최근에 담은 찜부터 찜 목록을 응답한다.**
   - 응답: `200` — 찜마다 상품, 상품명, 판매가, 판매 상태, 담은 일시
   - 판매 종료 상품은 상품명과 판매가 없이 보여준다

##### 항상 지켜야 할 규칙

6. **찜 목록에는 본인의 찜만 나온다.** 다른 회원의 찜은 포함하지 않는다.
