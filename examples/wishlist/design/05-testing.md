## Testing Strategy

### 테스트 전략 개요

요구사항 하나당 인수 테스트 묶음 하나를 만들고, 기준 하나당 테스트를 하나 이상 작성합니다. 모든 테스트는 상태, 에러 코드, **메시지까지** 검증합니다.

#### 1. 인수 테스트 (Acceptance Tests)

**대상:**
- 요구사항의 모든 기준

**도구:**
- `@SpringBootTest` + `MockMvc`, H2(MySQL 모드)
- 주문 기능의 `FakeProductCatalog`(장애 스위치, 호출 횟수 카운터)와 고정 `Clock`을 그대로 씀

**테스트 묶음:**

| 요구사항 | 테스트 묶음 |
|---|---|
| 1. 상품 찜하기 | `WishAddAcceptanceTest` |
| 2. 찜 해제 | `WishRemoveAcceptanceTest` |
| 3. 찜 목록 조회 | `WishlistQueryAcceptanceTest` |

**예시:**

```kotlin
@Test
@DisplayName("R1-3 찜 목록에는 상품을 100개까지 담을 수 있다")
fun `R1-3`() {
    addWish(member = 2, productId = 101).andExpect { status { isCreated() } }      // 99개 → 100개
    addWish(member = 3, productId = 101).andExpect {                                 // 100개
        status { isConflict() }
        jsonPath("$.code") { value("WISHLIST_FULL") }
        jsonPath("$.message") { value("찜 목록은 100개까지 담을 수 있습니다.") }
    }
}
```

#### 2. 동시성 테스트 (Concurrency Tests)

**대상:**
- 같은 회원이 같은 상품을 동시에 10번 담기 → 찜 1건, 모든 응답이 201 또는 200 (1.9)

**도구:**
- `ExecutorService` + `CountDownLatch`

#### 3. 테스트 기준 데이터

**고정 시각:** `2026-01-15T01:00:00Z`

**회원:**

| 회원 | 찜 | 용도 |
|---|---|---|
| 1 | 없음 | 기본 (빈 찜 목록, 첫 찜하기) |
| 2 | 99개 (상품 301 ~ 399) | 한도 경계: 하나 더 담기 가능 |
| 3 | 100개 (상품 301 ~ 400) | 한도 경계: 더 담기 불가 |
| 4 | 101 · 103 · 999 (담은 일시 00:57 · 00:59 · 00:58) | 목록 정렬, 판매 중지, 판매 종료 |

**상품 (FakeProductCatalog, 주문 기능과 같은 데이터에 더함):**

| 상품 ID | 상품명 | 판매가 | 판매 여부 | 용도 |
|---|---|---|---|---|
| 101 | 아메리카노 | 4,500 | 판매 중 | 기본 찜 |
| 103 | 시즌 한정 케이크 | 7,000 | 판매 중지 | 판매 중지도 담을 수 있음, 목록의 판매 중지 |
| 301 ~ 400 | 찜 상품 001 ~ 100 | 1,000 | 판매 중 | 한도 경계 데이터 |
| 999 | — | — | 없음 | 존재하지 않는 상품, 목록의 판매 종료 |

#### 4. 주요 테스트 시나리오

**찜하기:**
- 회원 1이 101 담기 → 201, 다시 담기 → 200 기존 찜 (담은 일시 그대로)
- 회원 2가 101 담기 → 201 (100개), 회원 3이 101 담기 → 409 `WISHLIST_FULL`
- 카탈로그 장애 → 503, 999 담기 → 404, 103 담기 → 201
- 이미 찜한 상품은 카탈로그를 호출하지 않음 (호출 횟수 0)

**찜 해제:**
- 담은 상품 빼기 → 204, 없는 상품 빼기 → 204
- 카탈로그 장애 상태에서도 204, 호출 횟수 0

**찜 목록 조회:**
- 회원 1 → 빈 목록, 카탈로그 호출 0
- 회원 4 → 103, 999, 101 순서 / 판매 중지 · 판매 종료 · 판매 중, 회원 1의 찜은 없음
- 카탈로그 장애 → 503
